## 1. 収集する情報 / Information We Collect

### Pro版 / Pro Version
- JP: クラウドバックアップ用の匿名認証情報
- EN: Anonymous authentication information for cloud backup

- JP: バックアップ機能の利用時に、端末内の入力情報（お子様の名前、生年月日、マイルストーン記録など）がクラウドに保存される場合があります
- EN: When using the backup feature, input data (child name, date of birth, milestones, etc.) may be stored in the cloud.

- JP: 購入情報（RevenueCatを通じた課金情報）
- EN: Purchase information (billing data via RevenueCat)

---

## 2. 情報の利用目的 / Purposes of Use

- JP: データのバックアップおよび復元（Pro版）
- EN: Backup and restoration of data (Pro)

---

## 3. データの保存場所 / Data Storage

### クラウドストレージ（Pro版のみ） / Cloud Storage (Pro only)
- JP: バックアップ機能を利用する場合、データはFirebase（Google Cloud Platform）に保存されます。通信は暗号化され、安全に管理されます。
- EN: When using the backup feature, data is stored on Firebase (Google Cloud Platform). Communications are encrypted and securely managed.

---

## 5. 第三者サービスの利用 / Third-Party Services

### Pro版 / Pro Version
- JP: Firebase Authentication（匿名認証）
- EN: Firebase Authentication (anonymous auth)

- JP: Cloud Firestore（データ保存）
- EN: Cloud Firestore (data storage)

- JP: RevenueCat（課金管理）
- EN: RevenueCat (billing management)

---

## 6. データの削除 / Data Deletion

- JP: ユーザーは、アプリをアンインストールすることで、ローカルに保存されたすべてのデータを削除できます。クラウドに保存されたデータについては、お問い合わせいただければ削除いたします。
- EN: You can delete locally stored data by uninstalling the App. For data stored in the cloud, please contact us and we will delete it.
